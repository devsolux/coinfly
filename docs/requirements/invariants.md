# Binding invariant matrix

These contracts define the Coinfly 1.0.0 safety boundaries. Source and tests below establish the stated core behavior; they do not certify missing external integrations. The [implementation status](../implementation-status.md) records implemented capabilities and release gates. All authority, credential and broker evidence entering trusted interfaces must originate from an authenticated worker-owned integration; a constructible Python model or a test fixture is not independent evidence.

| ID | Binding contract | Enforcement | Verification and limit |
|---|---|---|---|
| CTX-01 | One account authority has at most one mutation-capable context. Environment, track, alias and run directory cannot create another authority owner. | [ContextKey](../../src/coinfly/domain/context.py), [ownership.py](../../src/coinfly/worker/ownership.py), [context_interlock.py](../../src/coinfly/risk/context_interlock.py) | [test_ownership.py](../../tests/worker/test_ownership.py), [test_context_boundaries.py](../../tests/architecture/test_context_boundaries.py). Local ownership does not fence other hosts or independent exchange clients. |
| CTX-02 | Requested configuration is immutable and separate from effective configuration. Structural commands require the current revision, epoch, preview digest and idempotent request identity. | [config/service.py](../../src/coinfly/config/service.py), [context_coordinator.py](../../src/coinfly/control/context_coordinator.py) | [test_context_coordinator.py](../../tests/control/test_context_coordinator.py) covers duplicate requests, conflicts and target barriers. |
| CTX-03 | Acceptance fences source entries immediately. No target mutation construction precedes committed source closedness and retirement. Completion leaves the target unarmed. | [context_coordinator.py](../../src/coinfly/control/context_coordinator.py), [stop_certificate.py](../../src/coinfly/risk/stop_certificate.py) | [test_context_coordinator.py](../../tests/control/test_context_coordinator.py), [test_paper_worker_flow.py](../../tests/integration/test_paper_worker_flow.py). Live lifecycle adapters remain unavailable. |
| CTX-04 | Reset clears transient decisions/grants, preserving journal history, reservations, loss state, unresolved facts and genuine book balances. Restart does not reseed or rearm. | [context_state.py](../../src/coinfly/strategy/context_state.py), [drawdown.py](../../src/coinfly/risk/drawdown.py), [paper_engine.py](../../src/coinfly/worker/paper_engine.py) | [test_context_reset_and_weights.py](../../tests/strategy/test_context_reset_and_weights.py), [test_paper_worker_flow.py](../../tests/integration/test_paper_worker_flow.py). |
| CTX-05 | Staging a replacement paper book atomically archives the retired source. Recovery verifies source facts/retirement, pending context and staged target financial provenance before restoring the source read-only. Explicit retry may refresh an expired proof only with unchanged valid retirement, without reseeding, redraining or rearming. | [paper_engine.py](../../src/coinfly/worker/paper_engine.py), [context_coordinator.py](../../src/coinfly/control/context_coordinator.py) | [test_paper_staged_recovery.py](../../tests/worker/test_paper_staged_recovery.py) covers failure after initialization before effective publication, expired-proof retry and archive/capital/fact corruption. | REALM-01 | SANDBOX financial state is synthetic and cannot be promoted into LIVE. | REALM-02 | Financial configuration has no environment, dotenv, key-file or financial CLI override. Native paths do not use a poisoned HOME variable. | [config/models.py](../../src/coinfly/config/models.py), [worker/paths.py](../../src/coinfly/worker/paths.py), [cli.py](../../src/coinfly/cli.py) | [test_context_boundaries.py](../../tests/architecture/test_context_boundaries.py), [test_ownership.py](../../tests/worker/test_ownership.py). |
| REGION-01 | GLOBAL/GERMANY requests restrict policy; neither authenticates legal entity, residency, permission or eligible products. Eligibility is decided only by the versioned capability resolver from verified account evidence, route, permissions and freshness; GERMANY selects the EEA contract models (spot, perpetual-style futures, dated futures) and a German-bound account can never route international no-expiry perpetuals under GLOBAL. | [capability.py](../../src/coinfly/venues/capability.py), [products.py](../../src/coinfly/domain/products.py), [routes.py](../../src/coinfly/venues/routes.py), [region_attestor.py](../../src/coinfly/venues/coinbase/region_attestor.py) | [test_capability_matrix.py](../../tests/venues/test_capability_matrix.py), [test_regional_routing.py](../../tests/venues/test_regional_routing.py). | KEY-02 | Desktop Coinbase setup credentials live only in the explicitly selected OS keychain. Verification against Coinbase with a real credential is user-initiated and was not performed by the test suite. |
| NET-01 | No sandbox-to-live fallback, arbitrary trading host, credential redirect or ambient proxy/netrc/TLS configuration. | [endpoint_profiles.py](../../src/coinfly/venues/coinbase/endpoint_profiles.py), [http_reader.py](../../src/coinfly/venues/coinbase/http_reader.py), [adapter_factory.py](../../src/coinfly/venues/coinbase/adapter_factory.py) | [test_http_boundary.py](../../tests/venues/test_http_boundary.py), [test_regional_routing.py](../../tests/venues/test_regional_routing.py). Positive Live spot transport composition is implemented; the genuine enrollment/evidence provider and native qualification remain unavailable by default. |
| MONEY-01 | All money uses finite exact Decimal values. Each journal transaction balances per asset and remains realm/scope attributed. Venue JSON never passes through a binary float: every venue parse site decodes JSON numbers as exact Decimal (NaN/Infinity refused) and request bodies refuse floats. | [decimal_math.py](../../src/coinfly/domain/decimal_math.py), [journal.py](../../src/coinfly/accounting/journal.py), [lots.py](../../src/coinfly/accounting/lots.py), [decimal_json.py](../../src/coinfly/venues/decimal_json.py) | [test_realm_and_balance_conservation.py](../../tests/accounting/test_realm_and_balance_conservation.py), [test_decimal_json.py](../../tests/venues/test_decimal_json.py). |
| ORDER-01 | Intent, payload hash, semantic uniqueness and reservation commit before the guarded dispatch claim. The final send gate serializes with context fencing. | [intent_store.py](../../src/coinfly/execution/intent_store.py), [dispatcher.py](../../src/coinfly/execution/dispatcher.py), [outbox.py](../../src/coinfly/execution/outbox.py) | [test_order_facts_and_outbox.py](../../tests/execution/test_order_facts_and_outbox.py), [test_ledger_crash_and_late_fill.py](../../tests/faults/test_ledger_crash_and_late_fill.py). |
| ORDER-02 | Proven early fills establish acceptance and update fills, journal, lots and reservations atomically. Live trade-ID namespaces still require certification. |
| ORDER-03 | UNKNOWN retains possible exposure, reservation and a sticky authority fence. A timeout, empty page, request label or alarm acknowledgment does not prove noncreation. | [reconciler.py](../../src/coinfly/execution/reconciler.py), [evidence.py](../../src/coinfly/execution/evidence.py), [supervisor.py](../../src/coinfly/worker/supervisor.py) | [test_order_facts_and_outbox.py](../../tests/execution/test_order_facts_and_outbox.py), [test_ledger_crash_and_late_fill.py](../../tests/faults/test_ledger_crash_and_late_fill.py). Reconciliation exposes no create method. |
| STOP-01 | STOPPED requires exact flatness, terminal orders, resolved creates, applied fills, fresh complete scope evidence and fenced tasks. Dust and expired proofs block completion. | [stop_certificate.py](../../src/coinfly/risk/stop_certificate.py), [recovery.py](../../src/coinfly/execution/recovery.py) | [test_stop_proof.py](../../tests/risk/test_stop_proof.py), [test_context_coordinator.py](../../tests/control/test_context_coordinator.py). | STOP-02 | Forced drains preserve slippage, participation, liquidity and deadline constraints. Missing data disables new work while existing safety services remain available. | [drain_policy.py](../../src/coinfly/risk/drain_policy.py), [paper_engine.py](../../src/coinfly/worker/paper_engine.py), [supervisor.py](../../src/coinfly/worker/supervisor.py) | [test_paper_worker_flow.py](../../tests/integration/test_paper_worker_flow.py). Current integrated exits are spot paper only. |
| LATE-01 | Newly discovered source exposure invalidates source retirement and fences target admissions. Tombstones retain attribution and invalidated proofs remain discoverable through original-context listings/history. | [fact_reducer.py](../../src/coinfly/execution/fact_reducer.py), [slot_service.py](../../src/coinfly/control/slot_service.py) | [test_ledger_crash_and_late_fill.py](../../tests/faults/test_ledger_crash_and_late_fill.py), [test_slot_service.py](../../tests/control/test_slot_service.py). | SLOT-01 | Start grants scheduler permission without forcing a purchase. Stop/Delete persist exclusion; Delete/Edit wait for stop proof. | AUTO-01 | The worker owns the autonomous loop: strategy definition, universe selection, slot ownership and budget, sensory warm-up, decision, admission and execution. Scripted fixtures and synthetic feeds are labeled in every record. | [automation.py](../../src/coinfly/worker/automation.py), [ownership.py](../../src/coinfly/strategy/ownership.py), [universe.py](../../src/coinfly/strategy/universe.py), [controllers.py](../../src/coinfly/strategy/controllers.py) | [test_automation_lifecycle.py](../../tests/worker/test_automation_lifecycle.py), [test_sensory_and_universe.py](../../tests/strategy/test_sensory_and_universe.py). | DATA-02 | Market observations carry their source label, sequence, observed/received times and lineage; regressions are ignored, gaps counted, silence detected by heartbeat timeout, stale data rejected before decisions. Public feeds carry no credential. | [observations.py](../../src/coinfly/market/observations.py), [feed.py](../../src/coinfly/market/feed.py), [coinbase_public.py](../../src/coinfly/market/coinbase_public.py), [websocket_client.py](../../src/coinfly/network/websocket_client.py) | [test_feeds.py](../../tests/market/test_feeds.py), [test_coinbase_public.py](../../tests/market/test_coinbase_public.py), [test_websocket_client.py](../../tests/network/test_websocket_client.py). | LIVE-01 | Live arming requires every listed external artifact plus an explicit bounded mandate; no setting, fixture or UI action satisfies a gate. The automation dispatches through one execution interface, verified at bind time; the live spot engine plans only against fresh venue account evidence and initiates each mutation at most once (venue dedup by `client_order_id`), accepts only positive identity, rejects only on documented definitive reasons, and keeps UNKNOWN as neither creation nor rejection until complete venue history names the client id. The body digest is a local signing binding; the JWT claims are the broker's. A qualification mandate is bounded (one instrument, ≤ 25 notional, ≤ 24 h, configuration no wider) and breaks the run/mandate circularity without weakening any gate. Derivatives routes inherit nothing from the spot engine. | [engine.py](../../src/coinfly/execution/engine.py), [live_spot_engine.py](../../src/coinfly/venues/coinbase/live_spot_engine.py), [live_arming.py](../../src/coinfly/operations/live_arming.py), [advanced_trade_orders.py](../../src/coinfly/venues/coinbase/advanced_trade_orders.py), [http_reader.py](../../src/coinfly/venues/coinbase/http_reader.py) | [test_live_spot_engine.py](../../tests/venues/test_live_spot_engine.py), [test_live_arming.py](../../tests/worker/test_live_arming.py), [test_advanced_trade_orders.py](../../tests/venues/test_advanced_trade_orders.py).
